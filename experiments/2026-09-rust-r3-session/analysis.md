# 分析

此前Rust已更新权威统计，但展示World的战报、GameStats仍停在准备阶段。挂接旧HUD会显示过期信息。prepare_scene还会丢弃全部Python展示组件，缺少会话所有权边界。

修复把显示所需数据从完整历史中分出：阵营小表按阵营规模传送；战报首批完整、后续追加。20项HUD契约覆盖三display、两模式、0/3/100容量、攻击、ticks、reset、UI滚动与万条历史隔离。21项会话契约覆盖生命周期、初始化/事件失败、线程设置/模式、dummy窗口全系统绘制。结构实验只说明此展示边界不随旧历史增长，不能外推观测/移动性能。

NativeSession从同一场景准备接口导入一次、退役旧系统、挂接原renderer/native输入。EventBus会捕获并打印异常；会话现在保存首个错误、立即关闭native，在下一step/display边界重新抛出，避免继续推进错误世界。正常关闭和初始化失败清理订阅。

Cocoa探针记录命令/tick完整状态与展示增量，渲染前后分别比较权威状态。6场景540帧中的558节点通过序列化回放，并在新进程重放压缩raw。export_state仅供验证，生产展示不依靠全量导出。

当前面板叠放、初始化重复构造renderer、其他展示冷组件及完整结算/host仍需后续审视；不以本检查点替代完整可玩入口。未测初始化成本/吞吐，不能推断30Hz容量，没有新Performance Frontier。
