# Analysis — E8 观测服务专项

## 1. Observation

诊断源 11d9927／9bb2fa 扩展：12148 请求、2617 tick、3010 观测完整重放一致。单条 1238、段首 750、段内后续 1022。2604 次构建公共事实，406 次复用公共事实但仍构建请求面板；没有一次非空请求面板完全命中。不能把全部段内请求叫作命中。

| 角色 | 请求数 | native 均值 | decode 均值 |
|---|---:|---:|---:|
| 单条 | 1238 | 1.159ms | 0.781ms |
| 段首 | 750 | 1.150ms | 0.989ms |
| 段内后续 | 1022 | 0.566ms | 0.901ms |

这些是开启诊断、含计数和缓存概要的成本，不是正式速度对照。decode 保留约 80ms 的慢样本。单条诊断也开一请求上下文；没有计 open/drop，不可据此声称服务收益。

## 2. Competing hypotheses

H1：World.get 每读一个组件都重新取得 EntityRef，同一实体共享定位可以降低扫描成本。H2：人口统计对三个 map.entry 逐 Unit clone 阵营 String，现有键也生成临时副本；借用键再一次转拥有键可以减少分配。两项分开实施，第二项使用 baseline ECS 访问，不叠加 H1。

## 3. Instrumentation / diagnostic changes

新增三种私有扫描模式：baseline、entity_ref、borrowed_census。默认 baseline，reset 恢复 baseline；合法切换使旧读段失效，无效模式在失效或世界写入前拒绝。既有公共 API18/schema5、查询顺序、请求授权和计数不变。

Census 保持三张 map、外部实体 ID 顺序和缺组件判断。临时键从 String 改为 &str；返回缓存前转为拥有 String，alive 向量移动，任何 ECS 借用都不逃逸。扫描仍 O(Units)，只将最多每 Unit 三次键复制改为每张 map 每存在阵营一次复制；没有跨写入复用或缩小观测。

正式筛选关闭诊断，保留全部 3010 观测/2617 tick、750 次段开闭每侧；service 包含 open/drop 一次，wire 返回区间、bytes、decode、consume、host overhead 单列且严格加和。总工作只累加含维护成本的 service，不再加分项。bootstrap 统一 enclosing presentation tick、27 个 100-tick 块、10000 次、seed42，末块按实际样本数加权。P99 为原始侧样本 nearest rank，同时检查 pooled 和最差侧。

## 4. Evidence

| 独立因子 | 服务均值改善 | 服务改善 95% 区间 | 所测总工作改善 | 总工作改善 95% 区间 | 组合门槛 |
|---|---:|---:|---:|---:|---|
| EntityRef 定位 | 2.773% | −0.0009–0.1239ms | −3.138% | −0.2202–0.0133ms | 未过 |
| census 借用键 | 9.157% | 0.1561–0.2884ms | 1.696% | −0.0598–0.1878ms | 未过 |

两次采样资源有效，均保留所有慢样本。census 服务 P99 3.4066→3.0226ms，总工作 P99 9.7321→8.9460ms；最差侧 P99 也改善。但是总工作 max 105.626→108.988ms，不能宣称所有尾部改善。第一项服务 max 94.427→101.133ms。

小型同二进制 bare-handler 归因：在第一次录制观测前的状态，5 个 ABBA/BAAB 诊断循环，各模式10次。census 0.3795→0.1717ms；响应和全部工作计数相同、世界状态未变。这支持冗余键分配是可消除成本；它既未包含授权/消费，也不是收益验收。

最终 131 个契约校验；两候选分别一轮固定输入重放，所有响应字节匹配独立旧输入、四侧完整增量和事件一致、消费命令摘要相同、最终完整状态匹配。新源没有重复 40994/9880 长 P2，不继承旧源全部验证范围。两次 RSS 最高观察约 1201/815MiB，不是受控内存收益或一般无泄漏证明。

## 5. Root cause

人口统计存在逐 Unit 的不必要临时 String 分配；同输出/计数的局部诊断和服务对照支持减少该成本。现有证据没有证明它足以改善所测总工作或实际帧，也没有把剩余噪声归因于 GC、调度器或别的具体系统。EntityRef 定位的稳定收益未证实。

## 6. Limits / rejected explanations

两轮 baseline 的绝对值不一样，禁止跨二进制/运行相减。三张统计 map 和所有实体仍保留；不是降低任务量。9.157% 仅对原 E8 encoded 服务基线，不可与之前缓存 8%/9.88% 简单相加。总工作不含真实接纳/显示链，没有整帧或容量结论；前900 tick 的 warm 标签只是描述性分层，主门槛使用全部样本。
